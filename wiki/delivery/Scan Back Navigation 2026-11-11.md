# 스캔 뒤로가기 수정 (2026-11-11)

## 범위

- 기준: `origin/dev`의 `b1e9890`, 브랜치 `fix/scan-back-navigation`.
- 팀원 제보 3~6번의 화면 복귀·이미지 확대·촬영 화면 반복 진입을 수정한다.
- 로그인 제보 1~2번은 이번 범위에서 제외했다. 정상 동작을 보증한다는 의미는 아니다.
- Spring/OCR 서버·DB·권한·의존성 버전은 변경하지 않는다. 서버 재배포는 필요 없다.

## 원인과 변경

| 제보 | 원인 | 변경 후 동작 |
|---|---|---|
| 3. 사진 선택 후 시스템 백 두 번에 폐기 팝업 | 크롭 시스템 백은 촬영본을 유지하지만 상단 취소는 초기화하여 정책이 달랐음 | 두 경로 모두 크롭을 취소하고 촬영본을 정리한 뒤 기존 카메라로 복귀. 다음 백은 스캔 종료 |

| 5. 확대 화면에서 백을 누르면 작성 취소 팝업 | 아래에 마운트된 review의 전역 BackHandler가 남아 이벤트를 가로챔 | 각 화면의 포커스 동안만 리스너 유지. 뷰어에서는 뷰어만 닫고 편집 내용 보존 |
| 6. 다른 화면의 백이 카메라로 이동하며 반복 | 뷰어 위에서 review의 이탈 콜백이 실행되어 scan 루트가 중복될 수 있음 | 숨은 리스너·빈 결과 가드 비활성화, 루트 스택 대상으로 스캔 종료. 원래 탭과 탭 상태 유지 |

스캔의 카메라 복귀 처리는 `useScanNavigation.toCamera`로 통일했다.
촬영 화면 닫기는 루트 `POP_TO`를 대상으로 하므로 중복된 하위 카메라가 종료 동작을 가로채지 않는다.
분석 취소·다시 촬영·연속 스캔에도 동일한 복귀 처리를 적용했다.
저장 완료의 홈·보관함 이동도 기존 탭으로 dismiss하여 탭 루트를 추가하지 않는다.

사진 보정 처리 중과 서버 저장 중에는 뒤로가기로 비동기 결과의 도착 화면을 없애지 않도록 보호한다.
결과 화면에서 재분류 중에는 기존처럼 작성 취소 확인 후 나갈 수 있다.
카메라 도움말이 열려 있으면 시스템 백은 도움말부터 닫는다.

앱의 스캔 스토어에는 작업 세대 검사를 추가했다. 초기화·분석 취소·다른 사진 선택 후 도착하는
이전 압축 결과, OCR 응답과 업로드 진행률은 무시한다. 이전 요청이 다음 요청의 취소 핸들이나
결과를 덮어쓰지 않으며, 압축을 취소한 뒤 업로드가 뒤늦게 시작되어 결과 화면으로 이동하는 경로도 막는다.
촬영 파일을 생성하는 중에도 닫기로 비동기 촬영 결과의 도착 화면을 없애지 않도록 보호한다.

## 검증

- `npm run test:release`: 기존 29개와 새 내비게이션·작업 취소 32개, 총 61개 통과.
- `npm run typecheck`, `npm run lint`: 통과, 린트 오류·경고 없음.
- 운영 환경 변수와 mock 비활성화로 Android production export 통과.
- 새 테스트는 설치된 Expo SDK의 실제 route parser, navigation action targeting,
  StackRouter reducer 및 useFocusEffect 구현을 실행한다. 네이티브 이벤트와 React 마운트 환경은 모킹한다.
- 촬영·갤러리 각각의 상단/시스템 백, 뷰어 복귀 시 초안 보존, 딥링크 진입,
  연속 스캔, 포커스 해제 후 리스너 정리, 중복 루트 제거와 기존 탭 상태 보존을 검사한다.
- 취소 후 늦은 압축 성공·실패, 늦은 OCR 성공·진행률, 다음 요청의 취소 핸들 보존과 정상 OCR 완료도 검사한다.
- 실제 Android 기기의 카메라 프리뷰·전환 애니메이션·검은 화면을 검증한 것은 아니다.
  특히 4번의 기기별 검은 화면 해결 여부는 아래 절차로 재확인해야 한다.

## 머지 후 팀원 확인

1. `dev` 머지 후 새 APK/AAB를 빌드한다. 기존 versionCode 10 파일에는 이 수정이 없다.
2. 촬영과 갤러리 선택 각각 크롭 화면에서 시스템 백을 누르고 다시 백을 누른다.
   첫 번째는 카메라, 두 번째는 진입 전 탭으로 돌아와야 한다. 폐기 팝업이 뒤늦게 뜨지 않아야 한다.
3. 같은 절차를 상단 취소·닫기로 반복한다. 카메라 중복·검은 화면이 없어야 한다.
4. OCR 결과에 값을 입력하고 이미지를 확대한다. 시스템 백은 이미지만 닫고 입력 내용은 유지해야 한다.
5. 결과 화면에서 시스템 백을 누르면 작성 취소 확인이 떠야 한다.
   계속 작성을 선택하면 유지되고, 나가기를 선택하면 기존 카메라로 돌아와야 한다.
6. 스캔을 종료한 뒤 문서 상세·알림·설정에 들어갔다가 시스템 백을 반복한다. 촬영 화면으로 재진입하면 안 된다.
7. 저장 후 계속 스캔을 여러 번 반복하고 완료·보관함 이동을 확인한다.
8. 권한 허용·거부 및 촬영 화면 재진입, 이미지 뷰어 닫기 연타도 확인한다.

이번 작업에서는 새 APK/AAB 생성, Play Console 업로드 및 공개 출시는 진행하지 않았다.
